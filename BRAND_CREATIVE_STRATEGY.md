## Industry Visual Language Analysis

### Nigerian Private School Design Patterns (2024-2025)

**Common Elements Across Top Schools:**
1. **Color Philosophy**: Earth tones (terracotta, brown, gold) dominate - connecting to cultural heritage
2. **Typography**: Serif headers for authority, sans-serif for accessibility
3. **Imagery**: Formal school photos, campus panoramas, student achievement galleries
4. **Layout**: Information-dense but organized; quick links for admissions
5. **Motion**: Subtle fades, slide-ins; rarely complex animations

**Competitor Deep Dive:**

| School | Visual Style | Key Innovation | Website Feel |
|--------|--------------|----------------|--------------|
| **Corona Schools** | Clean white canvas, bold red accents | 35,000+ alumni showcase | Premium, global |
| **Grange School** | Modern British, teal accents | STEM partnership highlights | Contemporary British |
| **Greensprings** | Warm gradient backgrounds | Scholarship exam countdown | Aspirational |
| **Celebration School** | Bold purples and golds | Fast facts infographics | Modern achievement |
| **Holy Trinity** | Traditional earth tones | Character-building focus | Moral foundation |

## Taste Skill Application: "Belonging" Visual Translation

### Taste Principle Deconstructed for Hillcrest

> **Taste is the synthesis of emotional intelligence and visual literacy.** It's not about following trends—it's about creating work that communicates what others *feel* but cannot articulate.

**Hillcrest's Taste Signature:**
- **Warm Precision**: Clean layouts that don't feel cold
- **Heritage Modernism**: Traditional typography elevated with contemporary spacing
- **Inclusive Luxury**: Premium feel accessible to all socioeconomic backgrounds
- **Hilltop Drama**: Cinematic vertical rhythm with mountain-ascent narrative

**Why This Works:**
Nigerian school parents in 2024+ expect both tradition AND innovation. Pure traditionalism feels outdated; pure modernism feels disconnected from heritage. Hillcrest's taste must straddle this line—elegant enough for the "premium" conversation, warm enough for "community."

## Motion & Interaction Principles (from manim-video)

### The "Breathing" Approach

1. **Opacity Layering**: Elements fade in from 0% → 100% (like a scene reveal)
2. **Staggered Entrance**: Timeline items appear 0.1s apart (rhythm, not chaos)
3. **Subtle Lift**: On hover, cards lift 4px with shadow intensification
4. **Mountain Slide**: Hero mountain silhouette slides up 20px on page load

### Micro-interaction Library

```css
/* Button hover */
.btn:hover {
  transform: translateY(-2px);
  box-shadow: var(--shadow-lift);
}

/* Timeline item reveal */
@keyframes fade-in-up {
  from { opacity: 0; transform: translateY(20px); }
  to { opacity: 1; transform: translateY(0); }
}
```

## Typography System (Taste Amplified)

| Element | Font | Size | Weight | Letter Spacing | Use |
|---------|------|------|--------|----------------|-----|
| Display/Hero | Lobster | 4-5rem | 400 | -0.02em | "Oh Hillcrest College" |
| Section Titles | Cormorant Garamond | 2.5rem | 600 | -0.01em | "Our Journey" |
| Body Headings | Outfit | 1.5rem | 600 | -0.01em | "About Us" |
| Paragraphs | Outfit | 1.125rem | 400 | 0.01em | Main content |
| Navigation | Outfit | 1rem | 500 | 0.02em | Menu links |
| CTAs | Lobster | 1.25rem | 400 | -0.01em | Buttons |

**Taste Note**: Lobster for display gives "Oh..." a lyrical quality. It's decorative but not kitschy because of proper letter spacing. Outfit for everything else maintains clean readability.
